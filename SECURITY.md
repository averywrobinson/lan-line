# Security

Please report security problems privately with GitHub's **[Report a vulnerability](https://github.com/averywrobinson/lan-line/security/advisories/new)** form rather than a public issue. Include the Lan-Line version, both operating systems, and steps to reproduce.

Known beta limitations (not vulnerabilities to report):
- Traffic between paired computers is not encrypted yet. The pairing code authenticates the connection, but anyone on the same network can read what is sent. Use Lan-Line on networks you trust.
- The beta builds are not code-signed or notarized.
